// POST /auth/login
app.post("/auth/login", limiter,
  async (req, res) => {
    const { email, password } = req.body;
    const user = await users.byEmail(email);

    // mesmo custo com ou sem usuário:
    // o tempo de resposta não entrega
    // quem tem conta
    const ok = await argon2.verify(
      user?.hash ?? DUMMY_HASH, password);

    if (!user || !ok)
      return res.status(401)
        .json({ error: "invalid credentials" });

    const jwt = await sign({ sub: user.id },
      { expiresIn: "15m" });
    res.cookie("sid", jwt, { httpOnly: true,
      secure: true, sameSite: "lax" });
    res.sendStatus(204);
  });

Sobre

Fundamentos antes de tudo.

Desenvolvedor web. A curiosidade chegou antes da profissão e continua mandando.

Problema entendido a fundo, objetivo claro antes do código, o todo dividido em partes. Simples por escolha, sólido por método.
como eu resolvo problemas

Aos catorze, em 2021, as aulas eram online por causa da pandemia. Passando o dia inteiro na frente da tela, comecei a ficar curioso sobre como aquilo tudo funcionava por dentro. Fui atrás de aprender a fazer sites.

O site foi só a porta de entrada. Logo vi que o difícil não era a página, era tudo que existe embaixo dela: servidor, banco, rede, o sistema inteiro conversando. É aí que fundamento faz diferença, e é dominar essa base que me deixa calmo diante de problema difícil.

Desse jeito de aprender saiu um jeito de construir: entender primeiro, construir pra durar. Hoje isso vai de automações a produtos completos, e os minisites aqui do site são o laboratório onde eu me divirto.
